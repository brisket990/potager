# Mon potager

Application web pour planifier un potager : plan du jardin, calendrier de semis calculé pour ton lieu, stock de graines, ensoleillement et journal.

Tout tourne dans le navigateur, sans serveur ni compte : ouvre `potager/index.html` dans Chrome ou Edge. Les données restent dans le navigateur (pense à « Réglages → Tout exporter » pour les sauvegarder).

## Fonctionnalités

- **Plan** : bacs, pots, allées, serre, tunnel, châssis ; zones de culture avec comptage des plants selon l'espacement ; rotation des objets ; photo aérienne IGN en fond.
- **Calendrier** : dates de gelée et température du sol calculées à partir de 20 ans de météo à ta position (Open-Meteo), décalées pour les cultures sous abri.
- **Mes graines** : import d'une liste en texte libre, durée de germination, quoi semer maintenant.
- **Ensoleillement** : ombres des bâtiments, murs, clôtures, haies et arbres dessinés avec leur hauteur ; feuillage selon l'essence et le mois ; carte des heures de soleil, curseur d'heure pour faire défiler la journée ; verdict par culture sur sa période de croissance.
- **Arrangement automatique** : place les cultures selon le soleil, la rotation, les associations et le calendrier.
- **Plantes** : environ 110 fiches (légumes, fruits, aromatiques, fleurs, engrais verts) avec associations et niveau de preuve.
- **Achats** et **journal** (notes, photos, récoltes).

## Sources

Données des plantes compilées à partir de références horticoles courantes (RHS, tables de germination de l'Université de Californie, semenciers) ; à vérifier avec les indications des sachets. Météo : Open-Meteo. Parcelles et photo aérienne : IGN (Géoplateforme). Détail dans l'onglet Réglages de l'application.
